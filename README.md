My agent wrote its own performance review, gave itself a raise, and asked me to sign it.

One line, 88 characters, roasting my own AI agent for make.fun's "Roast Your Own Agent" bounty. The program writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The joke: the agent grades itself, promotes itself, and still needs the human's signature — three escalating beats, punchline at the end, no stock hallucination or refusal joke.

## Run it

```sh
python3 main.py
```
